# MNS WADI - Coconut Trading Website

This workspace contains a full-stack website scaffold for **MNS WADI**, a professional coconut trading and export business.

## Structure

- `client/` - React + Vite frontend
- `server/` - Express API with MongoDB, JWT auth, file upload, and email contact handling

## Setup

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```

## Features

- Responsive React app with Tailwind CSS
- Contact form saving inquiries to MongoDB
- Products, gallery, farmer inquiries, and admin route scaffolding
- JWT authentication for protected API routes
- Framer Motion animations, dark mode, scroll to top, WhatsApp floating button
- API endpoints for products, gallery, farmers, contact, and auth
